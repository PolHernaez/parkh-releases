# ParkMind

On és el cotxe i en quin estat l'has deixat. App d'Android.

**Descarregar:** [ParkMind.apk](https://github.com/PolHernaez/parkmind-releases/releases/latest/download/ParkMind.apk) (sempre l'última versió).

Obre l'arxiu al mòbil i instal·la'l. Les versions següents les avisa i les instal·la la mateixa app.

Tot es queda al mòbil: no hi ha compte, ni servidor, ni analítiques.
